Module 6 Lab Session 1 & 2

Comparison of the lab PDFs, repository implementation, and observed runtime outputs

Prepared from the available repository and PR materials

What the lab PDFs requested

  • Build a REST contract for Course and Enrollment resources
  • Use DTOs and validation instead of returning EF entities directly
  • Return 400 and 409 responses for validation and business-rule errors
  • Add pagination, filtering, sorting, and audit behavior

What the repository currently implements

  • Custom authentication with a training header
  • Request logging middleware with correlation IDs
  • A secured assessments endpoint
  • An enrollment service with structured logging
  • An enrollment worker that resolves scoped services safely

Verified runtime results

  • Build: dotnet build succeeded
  • Unauthorized: 401 Unauthorized from /api/assessments/results
  • Authorized: 200 OK with the training header
  • Worker: 200 OK from /api/enrollments/worker-smoke

Conclusion

The repository shows the architectural patterns taught by the labs, but it does not yet fully match the full Course/Enrollment contract described in the Module 6 PDFs.
